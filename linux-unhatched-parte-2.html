Permissões e arquivos no Linux

Entenda quem pode ler, alterar, executar, copiar, mover e apagar arquivos em um sistema Linux.

🔐 rwx🛠 chmod👤 chown📄 cat/head/tail⚠ rm com cuidado

Diagnóstico visual

Como ler as permissões no ls -l

Clique nos blocos da linha de permissão para explicar cada parte.

sysadmin@localhost:~/Documents$ ls -l hello.sh
-rw-r--r-- 1 sysadmin sysadmin 647 Dec 20 2017 hello.sh
- rw- r-- r-- dados
O primeiro caractere indica o tipo: '-' é arquivo comum; 'd' é diretório; 'l' é link simbólico.
A tabela que evita confusão

Permissões r, w, x: arquivo não é diretório

A mesma letra tem efeito diferente dependendo do alvo. Use as abas para comparar.

PermissãoSignificadoExemplo
r · readLer ou copiar o conteúdo do arquivo.cat arquivo.txt
w · writeModificar ou substituir o conteúdo.Editar um texto ou sobrescrever dados.
x · executeExecutar como programa ou script../hello.sh
PermissãoSignificadoExemplo
r · readListar nomes dentro do diretório.ls Pasta
w · writeCriar, apagar ou renomear entradas no diretório.mv, rm, touch
x · executeEntrar/travessar o diretório.cd Pasta

r = olhar

Você enxerga ou lê o conteúdo.

w = mudar

Você altera o conteúdo ou a lista de nomes de uma pasta.

x = entrar/rodar

Em arquivo, executa. Em diretório, permite atravessar.

Alterando acesso

O comando chmod no modo simbólico

chmod muda o modo de acesso. A lógica é montar uma frase curta: para quem? o que fazer? qual permissão?

chmod [conjunto][ação][permissão] arquivo
uusuário/dono
ggrupo
ooutros
atodos
+adicionar
-remover
=definir exatamente
rwxler, escrever, executar
$ chmod u+x hello.sh     # dono ganha execução
$ chmod go-r segredo.txt # grupo e outros perdem leitura
$ chmod a=rw relatorio.txt # todos ficam com leitura e escrita, sem execução
Prática guiada

Transformando um texto em script executável

O erro “Permission denied” pode significar que o arquivo existe, mas não tem permissão de execução para você.

Ponto didático: não basta o arquivo terminar em .sh. O sistema olha as permissões.
$ ./hello.sh
bash: ./hello.sh: Permission denied

$ ls -l hello.sh
-rw-r--r-- 1 sysadmin sysadmin hello.sh

$ chmod u+x hello.sh
$ ./hello.sh
______________
( Hello World! )
--------------
Dono e grupo

Mudando propriedade com chown

O dono de um arquivo normalmente é quem o cria. Para trocar a propriedade, em geral é necessário acesso administrativo.

👤

Dono

Usuário proprietário do arquivo. É o primeiro grupo de permissões depois do tipo.

sudo chown root hello.sh
👥

Grupo

Conjunto de usuários que compartilham permissões sobre o arquivo.

sudo chown root:adm log.txt
Atenção: ao transferir o arquivo para root, o usuário anterior pode perder privilégios e passar a ser tratado como grupo ou outros.
Leitura no terminal

Visualizando arquivos: cat, head e tail

Escolha a ferramenta pelo tamanho do arquivo e pela informação que deseja encontrar.

cat

Mostra tudo de uma vez. Bom para arquivos pequenos.

$ cat animals.txt
1 retriever
2 badger
3 bat

head

Mostra o início. Por padrão, 10 linhas. Use -n para escolher.

$ head -n 2 alpha.txt
A is for Apple
B is for Bear

tail

Mostra o fim. Muito usado para verificar logs recentes.

$ tail -n 2 alpha.txt
Y is for Yellow
Z is for Zebra
Criando cópias

Copiar com cp e criar dados com dd

📋

cp

Copia de uma origem para um destino. Você precisa conseguir ler a origem e escrever no destino.

$ cp /etc/passwd .
# copia para o diretório atual
💽

dd

Copia dados em baixo nível. Pode criar arquivos de teste, imagens e cópias brutas.

$ dd if=/dev/zero of=/tmp/swapex bs=1M count=50
if= origem
→
bs= tamanho do bloco
→
count= quantidade
→
of= destino
Operações que mudam o sistema

mv move ou renomeia; rm apaga de verdade

🚚

mv

O comportamento depende do destino: se for outra pasta, move; se for outro nome na mesma pasta, renomeia.

$ mv people.csv Work       # mover
$ mv animals.txt zoo.txt  # renomear
🗑️

rm

No terminal Linux não há lixeira por padrão. Remover pode ser permanente.

$ rm linux.txt
$ rm Work
rm: cannot remove 'Work': Is a directory
$ rm -r Work
Regra de ouro: antes de usar rm -r, confirme o caminho com pwd e liste o alvo com ls.
