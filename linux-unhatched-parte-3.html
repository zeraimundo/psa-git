Filtro poderoso

O comando grep procura padrões em texto

Clique nos símbolos para revisar o significado de cada elemento básico de expressão regular.

Regex essencial

^ — Âncora de início: o padrão precisa aparecer no começo da linha. Exemplo: ^root encontra linhas que começam com root.
# Exemplos rápidos
$ grep '^root' /etc/passwd
root:x:0:0:root:/root:/bin/bash

$ grep 'bash$' /etc/passwd
aluno:x:1000:1000:Aluno:/home/aluno:/bin/bash
Mini laboratório

Teste mental: o que cada grep retorna?

Use este slide para perguntar antes de revelar o resultado no terminal.

Arquivo: profile.txt

Hello my name is Joe.
I am 37 years old.
My favorite food is avocados.
I work in room 204.

Comandos

  1. grep '^[A-Z]' profile.txt
    Linhas que começam com letra maiúscula.
  2. grep '[0-9]' profile.txt
    Linhas que possuem algum número.
  3. grep 's\.$' profile.txt
    Linhas que terminam com “s.”.
Dica didática: peça que a turma destaque o “padrão” antes de pensar no comando. O segredo do grep é transformar uma pergunta em padrão textual.
Controle básico do sistema

shutdown e passwd

Dois comandos simples, mas que exigem responsabilidade: desligar um sistema afeta todos; trocar senha muda o acesso.

⏻

Desligamento seguro

O shutdown encerra o sistema de forma controlada e pode avisar usuários conectados.

root@linux:~# shutdown now
root@linux:~# shutdown +5 "Update!"
🔑

Alteração de senhas

Usuário comum altera a própria senha. O root pode alterar a senha de qualquer usuário.

aluno@linux:~$ passwd
Current password:
New password:
Retype new password:
password updated successfully
Diagnóstico de rede

Interfaces e conectividade: ifconfig, ip e ping

Antes de culpar o site, descubra se a máquina tem IP, se a interface está ativa e se os pacotes chegam ao destino.

Roteiro de verificação

  1. Ver IP e interface: ifconfig ou ip addr
  2. Testar loopback: ping -c 4 127.0.0.1
  3. Testar outro host: ping -c 4 8.8.8.8
  4. Testar nome: ping -c 4 ifpb.edu.br
$ ping -c 4 yahoo.com
4 packets transmitted, 4 received
0% packet loss

$ ip addr show
2: eth0: <BROADCAST,MULTICAST,UP>
    inet 192.168.1.35/24
Sistema em execução

Processos: o sistema trabalhando por trás

Cada comando em execução vira um processo. O ps ajuda a descobrir quem iniciou, qual PID recebeu e qual comando está rodando.

# Todos os processos (-e) em formato completo (-f)
aluno@linux:~$ ps -ef
UID        PID  PPID  C STIME TTY          TIME CMD
root         1     0  0 19:16 pts/0    00:00:00 /sbin/init
aluno       79    69  0 19:16 pts/0    00:00:00 -bash

UID

Usuário dono do processo.

PID

Número único do processo.

TTY

Terminal onde está rodando.

CMD

Comando que iniciou o processo.

Instalar e atualizar softwares

Gerenciamento de pacotes com APT

Em distribuições Debian/Ubuntu, o APT conversa com repositórios oficiais para buscar, instalar, atualizar e remover programas.

Ciclo seguro de instalação

apt-get update→apt-cache search→apt-get install

Primeiro atualize a lista local, depois procure o pacote e só então instale.

Atualizar sistema

root@linux:~# apt-get update
root@linux:~# apt-get upgrade

O upgrade atualiza os pacotes já instalados para versões disponíveis nos repositórios.

Remoção de pacotes

remove ou purge?

Os dois removem o software, mas têm consequência diferente nos arquivos de configuração.

🧹

apt-get remove

Remove o programa, mas preserva arquivos de configuração. Útil quando você pode reinstalar depois mantendo preferências.

root@linux:~# apt-get remove tree
🔥

apt-get purge

Remove o programa e também seus arquivos de configuração. É uma limpeza mais profunda.

root@linux:~# apt-get purge tree
Analogia rápida: remove é desinstalar o aplicativo. purge é desinstalar e apagar também as preferências.
Entrada e saída

Redirecionamento de I/O

A saída padrão de um comando normalmente vai para a tela, mas podemos gravá-la em arquivos.

⚠️

Sobrescrever com >

Cria ou substitui o conteúdo do arquivo. Se o arquivo já existir, o conteúdo anterior é apagado.

$ echo "Hello" > file.txt
# file.txt contém apenas Hello
➕

Anexar com >>

Adiciona ao final do arquivo, preservando o conteúdo já existente.

$ echo "World" >> file.txt
# file.txt contém Hello e World
Pensamento de SysAdmin

Comandos viram ferramentas combinadas

O poder do Linux aparece quando usamos um comando para gerar dados, outro para filtrar e outro para salvar o resultado.

# Salvar usuários com shell bash em um relatório
$ grep '/bin/bash$' /etc/passwd > usuarios_bash.txt

# Acrescentar processos do usuário atual no fim do relatório
$ ps -ef | grep aluno >> usuarios_bash.txt

1. Gerar

/etc/passwd e ps -ef fornecem dados.

2. Filtrar

grep separa o que interessa.

3. Registrar

> ou >> gravam o resultado.

Editor clássico do Linux

O vi/vim funciona por modos

No vi, digitar texto e executar comandos são ações de modos diferentes. Esse é o ponto que mais confunde iniciantes.

⌨️

Modo de Comando

Modo inicial. Movimenta cursor, copia, deleta e chama outros modos. Volte com Esc.

✍️

Modo de Inserção

Permite digitar texto. Entre com i, a ou o.

:

Modo Ex

Salvar, sair e buscar. Entre com : ou / a partir do modo de comando.

Comandoi/a/o →InserçãoEsc →Comando: →Ex

Comando ExResultado

Atividade rápida

Desafio final em dupla

Uma prática curta para consolidar os comandos da aula em sequência.

Missão

  1. Crie um arquivo relatorio.txt usando redirecionamento.
  2. Adicione uma segunda linha usando >>.
  3. Liste os processos com ps -ef e filtre seu usuário.
  4. Teste a rede com ping -c 4.
  5. Abra o relatório no vi, altere, salve e saia.

Modelo de comandos

$ echo "Relatório Linux" > relatorio.txt
$ echo "Aluno: José" >> relatorio.txt
$ ps -ef | grep aluno
$ ping -c 4 ifpb.edu.br
$ vi relatorio.txt
Regra da prática: explique o que cada comando faz antes de executar.
