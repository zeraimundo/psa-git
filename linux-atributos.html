Atributos Estendidos

Blindando o Linux com chattr e lsattr.

Duas ideias para esta aula: impedir mudanças e permitir apenas acréscimos.

Exemplos: proteger um arquivo de configuração de rede e preservar um registro de acessos.

PSA • Debian 13

1. Além das permissões

Permissões: quem pode?rwx controla leitura, escrita e execução. O chmod ajusta essas permissões.
Atributos: o que pode acontecer?O arquivo pode ficar imutável ou aceitar somente acréscimos.

chattr altera os atributos. lsattr mostra os atributos.

Pense em uma proteção adicional contra alterações por engano. Um administrador autorizado pode retirá-la.

PSA • Debian 13

2. Consultar com lsattr

Antes de alterar algo, consulte:

lsattr firewall_rules.sh
--------------e----- firewall_rules.sh

Saída ilustrativa. A letra e indica uma forma de organizar os dados no disco, comum no ext4; não significa arquivo protegido.

-RInclui o conteúdo das subpastas.
-aInclui arquivos ocultos.
-dMostra a própria pasta, em vez do conteúdo.
PSA • Debian 13

3. Proteger com +i

i = imutável. Bloqueia novas alterações, renomeação e remoção enquanto estiver ativo.

sudo chattr +i firewall_rules.sh
lsattr firewall_rules.sh

1. A primeira linha ativa a proteção.
2. A segunda consulta o resultado: procure a letra i.

Depois de confirmar i, uma tentativa de remover o arquivo deve falhar. Essa falha é esperada.

PSA • Debian 13

4. Liberar com -i

Precisa editar? Retire a proteção primeiro:

sudo chattr -i firewall_rules.sh
lsattr firewall_rules.sh

A letra i deve desaparecer. Edite o arquivo e use +i novamente para proteger a nova versão.

+ acrescenta o atributo. − retira o atributo.

Root também precisa retirar i antes dessas alterações. A proteção não é absoluta contra quem controla a administração.

PSA • Debian 13

5. Acrescentar com +a

a = somente acréscimo. Permite incluir conteúdo no final; impede substituir o conteúdo anterior ou apagar o arquivo.

sudo chattr +a access.log
lsattr access.log
echo "Novo acesso" >> access.log

Confirme a letra a antes do teste. O operador >> acrescenta uma linha sem apagar as anteriores.

Para liberar depois: sudo chattr -a access.log.

PSA • Debian 13

6. Uma seta ou duas?

>> acrescenta: funciona no arquivo com a.

echo "Novo acesso" >> access.log

> substitui: deve falhar no arquivo com a.

echo "Hack" > access.log
cat access.log

Confira o resultado: “Novo acesso” fica no final; “Hack” não deve substituir o histórico.

PSA • Debian 13

7. Outras opções de chattr

+ / −Acrescentam ou retiram atributos.
=Define o conjunto de atributos ajustáveis; retira os demais ajustáveis.
-RAplica à pasta e ao conteúdo, recursivamente.
-VMostra detalhes e a versão do comando.
-fOculta a maioria dos erros; não remove bloqueios.
sudo chattr -R +i conf_backup

Protege a pasta de backup e seus arquivos. Para desfazer, troque +i por -i.

PSA • Debian 13

8. Outras letras do exemplo

dExclui o arquivo dos backups feitos pelo programa dump.
AEvita atualizar o horário do último acesso. É diferente de a minúsculo.
cRelacionado à compressão, quando implementada pelo sistema de arquivos.
sRelacionado ao apagamento seguro, quando implementado.

No ext4, c e s não têm esses efeitos implementados. Não conte com s para apagar dados com segurança.

Para lembrar: lsattr consulta; chattr altera; i bloqueia mudanças; a permite acréscimos.
