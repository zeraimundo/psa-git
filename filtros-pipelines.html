PSA • Debian 13 • 02

O terminal como oficina de dados

Entrada

Um comando lê arquivos ou recebe dados pela entrada padrão (stdin).

Transformação

Cada filtro resolve uma tarefa: selecionar, ordenar, combinar ou formatar.

Saída

O resultado segue pela saída padrão (stdout). Mensagens de erro usam stderr.

grep ERROR logs/acesso.log | sort | nl | tee relatorios/erros.txt
O pipe | conecta a saída padrão de um comando à entrada do próximo. Ele não transporta automaticamente as mensagens de erro.
PSA • Debian 13 • 03

Pipes e redirecionamentos

| — conectar

sort dados/numeros.txt | nl
Entrega as linhas ordenadas ao numerador.

> — gravar

sort dados/numeros.txt > numeros.ord
Cria ou substitui o arquivo de saída.

>> — acrescentar

echo "Fim" >> relatorios/log.txt
Preserva o conteúdo anterior e adiciona uma linha.

tee — copiar a saída

sort dados/numeros.txt | tee numeros.ord
Grava no arquivo e envia os mesmos dados à saída padrão.

Não use sort arquivo > arquivo: o shell esvazia o destino antes de o comando ler a entrada. Use outro arquivo ou sort -o arquivo arquivo.
PSA • Debian 13 • 04

sort: escolher o critério

Texto ou número?

Sem opções, compara texto conforme a localidade. -n interpreta números; -r inverte; -nr combina os dois.

Unidades e repetições

-h interpreta sufixos como K, M e G. -u mantém uma linha por chave de ordenação igual; em linhas completas, elimina repetições exatas.

sort dados/numeros.txt
sort -n dados/numeros.txt
sort -nr dados/numeros.txt
sort -nu dados/numeros.txt
LC_ALL=C sort -h dados/disco.txt
Antes de clicar no laboratório: por que o texto “10” aparece antes de “2”? Para reproduzir os exemplos com ponto decimal, usamos LC_ALL=C.

PSA • Debian 13 • 06

sort: campos e separadores

nome:pontos
ana:10
bruno:2
carla:8

Uma chave bem delimitada

sort -t : -k2,2n placar.txt

-t :: separador dois-pontos.
-k2,2n: somente campo 2, numérico.
-k2,2nr: pontuação decrescente.

echo "ana:10" > placar.txt
echo "bruno:2" >> placar.txt
echo "carla:8" >> placar.txt
sort -t : -k2,2n placar.txt
-k2 usa do segundo campo até o fim da linha. -k2,2 restringe a chave ao segundo campo. sort -R embaralha grupos de chaves; para embaralhar linhas, explore shuf.
PSA • Debian 13 • 07

join: relacionar pela chave

Dois arquivos descrevem o mesmo identificador de máquina. O join combina as linhas cuja chave coincide.

usuarios.txt
m_004 carlos.santos
m_001 ana.paula
m_006 fernando.lima
m_003 julia.alves
m_002 maria.silva
m_005 lucas.costa
m_007 bruno.rocha

maquinas.txt
m_002 192.168.1.50 RH
m_004 192.168.1.22 Financeiro
m_001 192.168.1.10 TI
m_005 192.168.1.88 Backup
m_003 192.168.1.77 Marketing
m_006 192.168.1.99 Seguranca
m_008 192.168.1.120 Reserva
Por padrão, a chave é o primeiro campo; espaços e tabulações separam os campos. Os arquivos precisam estar ordenados pela mesma chave, com localidade consistente.
PSA • Debian 13 • 08

Preparar o join corretamente

export LC_ALL=C
sort -k1b,1 dados/usuarios.txt > usuarios.ord
sort -k1b,1 dados/maquinas.txt > maquinas.ord
join usuarios.ord maquinas.ord > resultado.txt
cat resultado.txt

Correspondências

join mostra os pares encontrados e coloca a chave uma única vez na saída.

Incluir sem par

join -a 1 também inclui as linhas do primeiro arquivo sem correspondência.

Somente sem par

join -v 1 mostra apenas as linhas do primeiro arquivo sem correspondência.

Aqui, m_007 existe só em usuários e m_008 só em máquinas. Use -v 2 para encontrar a máquina sem usuário.

PSA • Debian 13 • 10

nl: números que ajudam a ler

O padrão

nl numera linhas não vazias. As linhas vazias permanecem sem número.

Todas as linhas

nl -b a inclui as linhas vazias na contagem.

Formato

-n rz alinha à direita com zeros. -w 3 define largura 3; -s ": " define o separador.

Simulação didática: escolha um comando e compare a entrada com a saída. Execute os comandos reais no Debian durante a atividade.

#!/bin/bash

echo "Iniciando"

echo "Concluido"

Escolha um comando acima.
A largura padrão já é 6. nl -w 6 sozinho não acrescenta zeros; para isso, use -n rz.
PSA • Debian 13 • 11

tee: acompanhar e registrar

Gravar

echo "Inicio" | tee relatorios/log.txt
Mostra “Inicio” e substitui o conteúdo do arquivo.

Acrescentar

echo "Fim" | tee -a relatorios/log.txt
Mostra “Fim” e preserva as linhas anteriores.

Saída padrão: aguardando comando.
Arquivo: ainda não criado.
Simulação com estado: clique em “Acrescentar” várias vezes, depois em “Gravar”, e observe o conteúdo do arquivo.
PSA • Debian 13 • 12

tee, sudo e o shell

echo "teste" | sudo tee /etc/teste.conf
# Exemplo conceitual: grava com privilégios administrativos.

Quem grava com >?

Em sudo echo "teste" > /etc/teste.conf, o redirecionamento é feito pelo shell atual. Ele pode não ter permissão, mesmo quando o comando usa sudo.

Quem grava com tee?

Em echo "teste" | sudo tee /etc/teste.conf, o processo tee abre o arquivo com os privilégios concedidos por sudo.

Na atividade, trabalharemos apenas na pasta criada para o laboratório. Para salvar em mais de um destino: echo "teste" | tee copia1.txt copia2.txt.
PSA • Debian 13 • 13

Pipeline: do cadastro ao relatório

export LC_ALL=C
sort -k1b,1 dados/usuarios.txt > usuarios.ord
sort -k1b,1 dados/maquinas.txt > maquinas.ord
join usuarios.ord maquinas.ord |
  nl -b a -n rz -w 3 |
  tee relatorios/relatorio_final.txt
Escolha uma etapa para ver a transformação dos dados.
As duas ordenações preparam as entradas. O pipeline começa no join; o hífen em join - maquinas.ord permite receber o primeiro arquivo pela entrada padrão.

Preparação do laboratório

Copie o script, salve como setup_pipeline.sh e execute bash setup_pipeline.sh. Depois copie o comando cd exibido pelo script.

#!/bin/bash
set -e
LAB_DIR=$(mktemp -d "$HOME/lab_pipeline.XXXXXX")
mkdir -p "$LAB_DIR/dados" "$LAB_DIR/logs" "$LAB_DIR/relatorios"
cd "$LAB_DIR"

{
  echo 'm_004 carlos.santos'
  echo 'm_001 ana.paula'
  echo 'm_006 fernando.lima'
  echo 'm_003 julia.alves'
  echo 'm_002 maria.silva'
  echo 'm_005 lucas.costa'
  echo 'm_007 bruno.rocha'
} > dados/usuarios.txt

{
  echo 'm_002 192.168.1.50 RH'
  echo 'm_004 192.168.1.22 Financeiro'
  echo 'm_001 192.168.1.10 TI'
  echo 'm_005 192.168.1.88 Backup'
  echo 'm_003 192.168.1.77 Marketing'
  echo 'm_006 192.168.1.99 Seguranca'
  echo 'm_008 192.168.1.120 Reserva'
} > dados/maquinas.txt

{
  echo '10'
  echo '2'
  echo '8'
  echo '1'
  echo '2'
  echo '15'
  echo '3'
} > dados/numeros.txt

{
  echo '2.0G'
  echo '850M'
  echo '120K'
  echo '1.5G'
  echo '900K'
  echo '45M'
} > dados/disco.txt

{
  echo '#!/bin/bash'
  echo ''
  echo 'echo "Iniciando"'
  echo ''
  echo 'echo "Concluido"'
} > dados/exemplo.sh

{
  echo '2026-10-05 08:00:01 INFO Usuario ana.paula logou no sistema'
  echo '2026-10-05 08:03:15 WARN Tentativa de acesso invalido'
  echo '2026-10-05 08:10:55 ERROR Falha ao abrir banco de dados'
  echo '2026-10-05 08:11:02 INFO Usuario maria.silva acessou RH'
  echo '2026-10-05 08:15:44 ERROR Permissao negada'
  echo '2026-10-05 08:17:10 INFO Backup executado'
  echo '2026-10-05 08:20:33 WARN Uso alto de memoria'
  echo '2026-10-05 08:22:19 INFO Usuario julia.alves alterou relatorio'
  echo '2026-10-05 08:30:10 ERROR Servidor indisponivel'
} > logs/acesso.log

echo "Laboratorio criado em: $LAB_DIR"
echo "Para entrar, execute: cd \"$LAB_DIR\""
Cada execução cria uma pasta nova em seu diretório pessoal. Não exige root e não remove laboratórios anteriores. Todos os dados são criados com echo.

30–40 minutos • Em duplas: uma pessoa executa, a outra prevê e confere. Troquem de função na metade.

ATIVIDADE — FILTROS E PIPELINES (DEBIAN 13)

1. Execute o script de preparação e entre na pasta indicada.
2. Compare sort, sort -n, sort -nr e sort -nu em dados/numeros.txt.
   Explique por que 10 aparece antes de 2 na ordenação textual.

4. Ordene os dois cadastros pelo campo 1 e crie resultado.txt com join.
5. Identifique o usuário sem máquina e a máquina sem usuário.
   Compare join, join -a 1, join -v 1 e join -v 2.
6. Compare nl e nl -b a em dados/exemplo.sh.
   Mostre a diferença com nl -b a -n rz -w 3.
7. Grave uma linha com tee e acrescente outra com tee -a.
   Execute cat no destino e explique a diferença.
8. Gere relatorios/relatorio_final.txt com join | nl | tee.
9. Gere relatorios/erros.txt contendo somente as linhas ERROR,
   ordenadas e numeradas. Não altere o log original.

ENTREGA: os dois relatórios, os comandos executados e respostas
curtas às perguntas. Confira: 6 pares, 1 usuário sem máquina,
